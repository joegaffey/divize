divize // Divisionist Layered Point Codec

Lossy, progressive image compression: turn a raster into a sparse hierarchical point cloud, then rebuild it on the GPU as bytes arrive.

Divisionism, in code

Pointillism — Seurat, Signac — builds a picture from small, unmixed dabs of colour that the eye fuses into a luminous whole; placement is deliberate, guided by colour theory. DLPC is divisionism in code: a saliency-guided encoder replaces brush dabs with Voronoi cells, triangles and splats, and the GPU decoder optically "mixes" them as bytes arrive. Fidelity tracks mark density and viewing distance — the same tradeoff Seurat resolved with the placement of dots.

The idea

A highly parallel encoder (computer vision / ML) places points where they matter — near edges, texture, high-frequency detail — and packs them into a quantized binary stream. A cheap decoder renders them on the GPU (WebGPU/WebGL) layer by layer, so a scene solidifies progressively on the wire.

How it's layered

  • Layer 0 — a pure-Voronoi structural floor: few seeds, full coverage, 5-byte packets. Guarantees something solid, instantly.
  • Layer 1+ — refinement: more Voronoi seeds or alpha-blended geometric splats (8-byte packets) that sharpen detail only where it's needed.

Why experiments?

What's the minimum seed count a human still "reads"? Is pure progressive Voronoi or a hybrid splat floor more bits-for-clarity? Does analytic placement beat iterative or learned placement? Each repo folder is one self-contained experiment built to answer those.
