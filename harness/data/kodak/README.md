# Kodak test images

The 24 `kodim*.png` images in this directory are the classic **Kodak PhotoCD
PCD0992 lossless true-color test suite**, mirrored from
https://r0k.us/graphics/kodak/.

Per the mirror (r0k.us, Rich Franzen): the images *"have been released by the
Eastman Kodak Company for unrestricted usage"* — they are the standard suite
used across the industry for image-compression testing. Committed here so the
experiment pages and report deep-links can load them without a network fetch.

Source / credits: https://r0k.us/graphics/kodak/ (PhotoCD_credits.txt there).
